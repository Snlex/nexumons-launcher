# Nexumons Society

Launcher autonome Windows et macOS pour Kinetic 1.

- Society 1.1.4-SSV4.1.5A ; Minecraft 1.20.1 ; Forge 47.4.0 ; Java 17.
- Compte Microsoft propriétaire de Minecraft Java requis : le serveur est en online-mode.
- Téléchargement de l’archive officielle et des 396 fichiers depuis CurseForge/CDN, avec empreintes SHA-256 vérifiées. Les mods ne sont pas republiés sur GitHub.
- Instance isolée, installation transactionnelle et conservation des sauvegardes joueur.
- Canal GitHub kinetic1/society/manifest.json, indépendant de Cobbloria et de l’ancien pack Fabric.
- Mise à jour automatique de l’application via archive contrôlée ; premier téléchargement du nouveau moteur nécessaire.
- Compilations Windows x64, Mac ARM64 et Mac Intel ; tests d’ouverture natifs.
- Prévoir 4 Go de disque libre pour la première installation, puis environ 6–8 Go de RAM au jeu selon le PC.
- Mac : signature ad hoc, sans notarisation Apple. Au premier lancement, utiliser clic droit > Ouvrir ou Autoriser dans Confidentialité et sécurité si Gatekeeper le demande.

Le pack Society contient le fork Sunlit de Cobblemon basé sur 1.5.2, pas Cobblemon 1.8. Crédit : auteurs Society: Sunlit Cobblemon et auteurs de chaque mod ; les téléchargements restent sur leurs sources officielles.
